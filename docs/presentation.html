Проблема

«Вчера 100 000 ₽, сегодня 102 000 ₽. Покупать или ждать?»

Целевой сценарий

Октябрь 2026. Москва → Токио на сезон сакуры (вылет 20–26 марта 2027). Агрегаторы показывают цену сейчас, но не говорят, когда она будет минимальной.

Что отвечает платформа

  • календарь min-цен по датам вылета (туда / туда-обратно, любой состав пассажиров);
  • вердикт с объяснением каждого сигнала;
  • прогноз цены от сегодня до вылета: окно минимума и пик;
  • риски: новости региона, визовый лимит, встречи в календаре;
  • AI-помощник, который сам ищет цены по вопросу текстом.

Принцип: ядро — числа и правила, LLM — только интерфейс. LLM не знает сегодняшних цен и может их выдумать.

Аргументы

  • Объём и команда: 1 человек + ИИ-агент, сжатые сроки. Микросервисам и агентным фреймворкам некому служить.
  • Деплой: Streamlit Cloud = один Python-процесс без внешних БД → SQLite и модули работают «как есть».
  • Объяснимость: каждый движок отдаёт сигнал с текстом, оркестратор — прозрачная сумма.
  • Заменяемость: движки общаются словарями — скрейпер → Travelpayouts, эвристика → CatBoost, SQLite → Postgres без правки UI.

Как рождается вердикт BUY / WAIT / WATCH

📈 Динамика цены (последняя vs медиана истории)
📰 Новости региона
🗓 Встречи в день вылета

Скор: buy = +1, wait = −1, neutral/careful = 0. «careful» не меняет скор, но добавляет ⚠️. Порог «заметно дешевле» — 3% (CHEAP_DISCOUNT_PCT).

Новости региона

Почему не CatBoost: Google не отдаёт историю цен, поллер копит её с 24.10.2026 — учить не на чем. Кривая бронирования нормирована на сегодняшнюю реальную цену → работает для любого маршрута; в UI помечена как демо.

Как делали

Вайбкодинг: человек — продакт, ИИ-агент — разработчик

Цикл одного этапа

Подсвечивается по кругу. Самопроверка агента — py_compile, юнит-сценарии, Streamlit AppTest, живой запрос к Google — до показа человеку.

1. Строго поэтапно

После этапа — стоп, демо, валидация. Следующий этап — только после «ок».

2. Честность в UI

Синтетика помечена; «нет цен» ≠ «источник не отдаёт цены».

3. Объяснимость

Каждый вердикт — со списком сигналов и текстом.

4. Память в файле

HANDOFF.md — журнал для агента без памяти; смена Claude Code → Cursor без потери контекста.

5. Секреты не светим

Агент проверяет только наличие ключей, значения не печатает.

Главный урок

Дорогие ошибки агента — в допущениях об окружении: «облако видит гейтвей», «Streamlit перечитает модули».
